Privacy Policy – Eastkan Gaming Tools

Last updated: October 19, 2026

What this application is

"YouTube Toplu Ceviri" is a private tool used only by the owner of the Eastkan Gaming YouTube channel. It manages the channel's own videos: it adds translated titles and descriptions, tags and playlists. It is not offered to the public and has no other users.

Data the application accesses

Through the YouTube API Services, with the channel owner's authorization, the application reads and updates the Eastkan Gaming channel's own video titles, descriptions, tags, playlists, channel description and their translations. It does not access any other channel's data, viewers' personal data, comments or messages.

How the data is used and stored

The data is used only to update the channel owner's own YouTube content. Working copies (video IDs, titles, descriptions and progress logs) are kept in a private Google Sheet owned by the channel owner. No data is sold, shared with, or transferred to any third party, and no data is used for advertising.

Google and YouTube policies

This application uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy. The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from the Google security settings page: myaccount.google.com/permissions.
